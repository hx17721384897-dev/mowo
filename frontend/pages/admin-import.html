CSV格式说明

系统自动识别以下淘宝导出字段：

订单编号→ 系统外部订单号（幂等去重依据） 收货人姓名→ 收件人姓名 联系手机→ 手机号（需11位大陆号码） 省 / 市 / 区 / 详细地址→ 拼接为完整地址（≥10字符为有效） 宝贝标题 + 宝贝种类→ 组合后匹配SKU映射表 买家留言→ 买家备注（选填）

SKU匹配失败的订单将标记为「待确认SKU」，可在「异常待处理」页面人工指定后写入映射表。
