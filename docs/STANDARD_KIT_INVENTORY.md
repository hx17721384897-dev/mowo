# 标准材料包与零件库存

> 实施日期：2026-08-22  
> 当前状态：基础零件、已分装小包、标准材料包三层库存已经分开；采购、分装和材料包组装均已建立批次链及先进先出推荐；退回收货、隔离检查、新品回库、维修备用和补发任务已经实现首版。生产任务领料、移箱和逐件装箱仍待后续生产批次完成。

## 一、业务边界

系统将实物分为以下层级：

1. 产品结构/款式，例如标准款、盒状款；由 `MachineModel` 表示。
2. 可售 SKU，例如“标准款 + 5x5cm + 椴木板 + 12帧 + 原色”；由 `MachineModelSku` 表示。
3. 散装或基础零件，例如切好的 5.5cm 铁丝、木板、散装蜡粒。
4. 已分装零件，例如 12 根铁丝包、16 根铁丝包、润滑蜡小包。
5. 标准材料包，即按照某个 SKU 的材料清单组装完成、可以被生产任务领用的一整套配件。
6. 帧素材包，包含动画对应的打印帧，与标准材料包分开管理。

`SkuInventory.currentStock` 在本阶段明确表示该 SKU 已组装完成的标准材料包数量，不表示散装零件数量，也不表示已经装配完成的最终商品数量。

## 二、页面职责

### `admin-inventory.html`

- 是零件资料的唯一新增和编辑入口。
- 顶层明确分为“标准材料包、已分装小包、基础零件、退回检查”，三种库存并列展示。
- 新增基础零件和新增分装小包使用各自入口：系统自动确定类型并生成编码，员工不填写内部类型或编码。
- 名称和单位使用数据库共享的可管理下拉列表：点击展开，每个选项右侧 `×` 只删除该下拉选项，不删除已存在的零件、库存或历史记录；列表底部可填写并新增选项。名称选项按基础零件/分装小包分开，单位选项共用。
- 管理零件编码、类型、规格、单位、安全库存、采购周期和备注。
- 录入采购实收、到货次品、供应商和供应商批号。
- 把散装零件分装成已分装零件，并记录正常使用量、额外损耗和实际来源批次。
- 执行标准材料包入库；系统同步扣除零件并增加材料包库存。
- 管理可重复使用的箱码和库位基础信息。

### `admin-models.html`

- 管理产品款式和可售 SKU。
- SKU 由尺寸、材质、目标帧数、颜色和价格等规格组成。
- 只能从库存页已有零件中选择 SKU 所需零件及每套数量。
- 不能在款式页新增、编辑、入库或报损零件。

## 三、采购实收与误差

采购描述不直接换算成可用库存。系统以现场清点的实际合格数量为准：

```text
订购说明：50米铁丝，由工厂切成5.5cm
实际清点：120根
合格数量：118根
到货次品：2根
可用库存增加：118根
```

`MaterialReceipt` 保存订购说明、实际清点数、合格数、次品数、供应商、供应商批号、操作人和时间。合格数与次品数之和必须等于实际清点数。

铁丝、双面胶和蜡粒均遵守该规则。长度、重量或采购金额可以写入订购说明，但不能替代现场清点。

## 四、分装

已分装零件必须设置：

- 来源零件；
- 每一包需要多少来源零件。

例如“12根铁丝包”的来源是“5.5cm散装铁丝”，每包使用 12 根。分装 9 包并发现 2 根损耗时：

```text
正常使用：9 × 12 = 108根
额外损耗：2根
来源库存扣除：110根
已分装库存增加：9包
```

分装记录使用 `PREP-...` 编号。采购批次和分装记录不是同一个概念：同一批采购铁丝可以分多次分装；每次分装分别记录时间、数量和损耗，但来源仍可以是同一次采购。

2026-08-22 起，系统会按最早入库优先推荐具体到货批次。员工确认后才分装；特殊情况可在“更换来源批次”弹窗中看到批次、剩余量和库位并改选，后端始终校验所选数量。`MaterialPreparationInput.sourceReceiptId` 保存每一段实际来源，因此一次分装跨两个到货批次也能完整追溯。

散装蜡粒后续按“克”等最小可盘点单位入库；润滑蜡小包按“包”管理。每包克数尚未确定前，不建立正式分装配方。

## 五、SKU 材料清单

现阶段继续使用 `MaterialSkuBinding` 保存当前材料清单，并使用 `MachineModelSku.bomVersion` 标记版本号。每次整体保存材料清单，版本号加一。

材料清单示例：

| 零件 | 每套用量 |
|---|---:|
| 5x5cm 椴木板 | 1块 |
| 12根铁丝包 | 1包 |
| 12帧双面胶包 | 1包 |
| 小手机支架 | 1个 |
| 润滑蜡小包 | 1包 |
| 说明书 | 1份 |

组装入库时会把当时的零件名称、编码、规格、单位、每套用量和总用量保存为不可随当前配方变化的快照。修改新版本材料清单不会篡改旧组装记录。

## 六、材料包入库

员工操作上只有一次“材料包入库”：选择 SKU、填写套数，并可填写箱码、库位和备注。系统在一个数据库事务中完成：

1. 读取 SKU 当前材料清单。
2. 计算每种零件总用量。
3. 基础零件从 `MaterialReceipt`、分装小包从 `MaterialPreparationBatch` 按先进先出推荐来源批次。
4. 员工确认推荐结果后，原子扣除全部来源批次和物品总数。
5. 增加 `SkuInventory.currentStock`。
6. 写入 `KB-...` 组装记录和材料清单快照。
7. 如果填写箱码，增加该箱中的材料包数量。

`KitAssemblyConsumption` 保存每一种材料实际扣了哪些来源批次。组装弹窗会先展示批次编号、数量和库位，批次编号可点击查看详情。员工不需要记住 `RL/PREP/KB` 编号。

任一零件不足时整笔拒绝，不允许只扣除部分零件。旧的“商品发货时再扣零件”已经停止；发货不再重复扣减材料清单。

## 七、批次与箱码

- 采购批次回答“零件从哪里来”。
- `PREP` 分装记录回答“什么时候把散装零件分成小包”。
- `KB` 组装记录回答“什么时候按哪个配方组装了多少套材料包”。
- `BX` 箱码回答“材料包现在存放在哪里”。

当前编号实际前缀为：采购实收 `RCV`、分装 `PREP`、材料包组装 `KB`、退回收货 `RT`、退回合格材料包 `KR`。`LEGACY` 表示启用批次追踪前已有的期初余额，不代表新的采购或生产。

组装记录不等于实体箱子。一个箱码可以重复补入同一种 SKU 的多个组装记录，不会因为每次入库都增加新箱子。一个箱子首版只允许存放一种 SKU，防止现场拿错。

普通低价值材料包不逐套贴码。最终成品继续使用独立 `PU` 单件生产编号。高价值、特殊规格或容易混淆的材料包是否启用单件码，留到生产异常规则阶段决定。

## 八、退回、检查与补发

退货快递发出或仓库签收都不会直接恢复可售库存。首版流程为：

1. 客服在订单后台同意售后。
2. 仓库从售后卡片进入“登记退回收货”，生成 `RT` 编号并进入 `QUARANTINED` 隔离状态。
3. 仓库检查包装、使用情况、数量和可复用部件。
4. 未拆封、完整且检查合格的整套材料包生成新的 `KR` 回收批次，进入新品材料包库存；不会塞回原组装批次。
5. 已拆封的胶、蜡、铁丝不进入新品库存。可复用木板、支架等只进入 `serviceStock` 维修备用库存；报废、缺失和私人帧素材销毁只留记录，不增加库存。
6. 需要补发时创建新的 `PU-R` 生产任务，并通过 `replacementForId` 和 `aftersaleRequestId` 关联原任务及售后；原任务不重新打开。

私人定制帧素材无论外观是否完整，都不能进入公共帧素材库存。退回检查完成后，售后状态进入 `completed`；退款和资金冲正仍按首发人工流程处理。

新增或扩展的主要模型：

- `MaterialItem`：零件主数据及分装来源。
- `InventoryFormOption`：后台新增零件时可共享维护的名称和单位选项。
- `MaterialReceipt`：采购实收和到货次品。
- `MaterialPreparationBatch` / `MaterialPreparationInput`：分装和损耗。
- `MaterialSkuBinding`：当前 SKU 材料清单。
- `KitAssemblyBatch`：材料包组装入库和配方快照。
- `KitAssemblyConsumption`：材料包组装实际使用的来源批次。
- `KitContainer`：可重复使用箱码和当前数量。
- `InventoryReturnReceipt` / `InventoryReturnInspectionItem`：退回隔离、检查结论和回库结果。
