# 标准材料包与零件库存

> 实施日期：2026-08-22  
> 当前状态：零件实收入库、散装零件分装、SKU 材料清单、标准材料包组装入库和可复用箱码基础已经实现；生产任务领料、退回、移箱和严格供应批次分配仍待后续生产批次完成。

## 一、业务边界

系统将实物分为以下层级：

1. 产品结构/款式，例如标准款、盒状款；由 `MachineModel` 表示。
2. 可售 SKU，例如“标准款 + 5x5cm + 椴木板 + 12帧 + 原色”；由 `MachineModelSku` 表示。
3. 散装或基础零件，例如切好的 5.5cm 铁丝、木板、散装蜡粒。
4. 已分装零件，例如 12 根铁丝包、16 根铁丝包、润滑蜡小包。
5. 标准材料包，即按照某个 SKU 的材料清单组装完成、可以被生产任务领用的一整套配件。
6. 帧素材包，包含动画对应的打印帧，与标准材料包分开管理。

`SkuInventory.currentStock` 在本阶段明确表示该 SKU 已组装完成的标准材料包数量，不表示散装零件数量，也不表示已经装配完成的最终商品数量。

## 二、页面职责

### `admin-inventory.html`

- 是零件资料的唯一新增和编辑入口。
- 管理零件编码、类型、规格、单位、安全库存、采购周期和备注。
- 录入采购实收、到货次品、供应商和供应商批号。
- 把散装零件分装成已分装零件，并记录正常使用量和额外损耗。
- 执行标准材料包入库；系统同步扣除零件并增加材料包库存。
- 管理可重复使用的箱码和库位基础信息。

### `admin-models.html`

- 管理产品款式和可售 SKU。
- SKU 由尺寸、材质、目标帧数、颜色和价格等规格组成。
- 只能从库存页已有零件中选择 SKU 所需零件及每套数量。
- 不能在款式页新增、编辑、入库或报损零件。

## 三、采购实收与误差

采购描述不直接换算成可用库存。系统以现场清点的实际合格数量为准：

```text
订购说明：50米铁丝，由工厂切成5.5cm
实际清点：120根
合格数量：118根
到货次品：2根
可用库存增加：118根
```

`MaterialReceipt` 保存订购说明、实际清点数、合格数、次品数、供应商、供应商批号、操作人和时间。合格数与次品数之和必须等于实际清点数。

铁丝、双面胶和蜡粒均遵守该规则。长度、重量或采购金额可以写入订购说明，但不能替代现场清点。

## 四、分装

已分装零件必须设置：

- 来源零件；
- 每一包需要多少来源零件。

例如“12根铁丝包”的来源是“5.5cm散装铁丝”，每包使用 12 根。分装 9 包并发现 2 根损耗时：

```text
正常使用：9 × 12 = 108根
额外损耗：2根
来源库存扣除：110根
已分装库存增加：9包
```

分装记录使用 `PREP-...` 编号。采购批次和分装记录不是同一个概念：同一批采购铁丝可以分多次分装；每次分装分别记录时间、数量和损耗，但来源仍可以是同一次采购。

散装蜡粒后续按“克”等最小可盘点单位入库；润滑蜡小包按“包”管理。每包克数尚未确定前，不建立正式分装配方。

## 五、SKU 材料清单

现阶段继续使用 `MaterialSkuBinding` 保存当前材料清单，并使用 `MachineModelSku.bomVersion` 标记版本号。每次整体保存材料清单，版本号加一。

材料清单示例：

| 零件 | 每套用量 |
|---|---:|
| 5x5cm 椴木板 | 1块 |
| 12根铁丝包 | 1包 |
| 12帧双面胶包 | 1包 |
| 小手机支架 | 1个 |
| 润滑蜡小包 | 1包 |
| 说明书 | 1份 |

组装入库时会把当时的零件名称、编码、规格、单位、每套用量和总用量保存为不可随当前配方变化的快照。修改新版本材料清单不会篡改旧组装记录。

## 六、材料包入库

员工操作上只有一次“材料包入库”：选择 SKU、填写套数，并可填写箱码、库位和备注。系统在一个数据库事务中完成：

1. 读取 SKU 当前材料清单。
2. 计算每种零件总用量。
3. 检查全部零件库存。
4. 原子扣除全部零件。
5. 增加 `SkuInventory.currentStock`。
6. 写入 `KB-...` 组装记录和材料清单快照。
7. 如果填写箱码，增加该箱中的材料包数量。

任一零件不足时整笔拒绝，不允许只扣除部分零件。旧的“商品发货时再扣零件”已经停止；发货不再重复扣减材料清单。

## 七、批次与箱码

- 采购批次回答“零件从哪里来”。
- `PREP` 分装记录回答“什么时候把散装零件分成小包”。
- `KB` 组装记录回答“什么时候按哪个配方组装了多少套材料包”。
- `BX` 箱码回答“材料包现在存放在哪里”。

组装记录不等于实体箱子。一个箱码可以重复补入同一种 SKU 的多个组装记录，不会因为每次入库都增加新箱子。一个箱子首版只允许存放一种 SKU，防止现场拿错。

普通低价值材料包不逐套贴码。最终成品继续使用独立 `PU` 单件生产编号。高价值、特殊规格或容易混淆的材料包是否启用单件码，留到生产异常规则阶段决定。

主要页面和接口：

- `frontend/pages/admin-models.html`

新增或扩展的主要模型：

- `MaterialItem`：零件主数据及分装来源。
- `MaterialReceipt`：采购实收和到货次品。
- `MaterialPreparationBatch` / `MaterialPreparationInput`：分装和损耗。
- `MaterialSkuBinding`：当前 SKU 材料清单。
- `KitAssemblyBatch`：材料包组装入库和配方快照。
- `KitContainer`：可重复使用箱码和当前数量。
