### B2-B 地址隔离证据（2026-09-09）

- 源码：`routes/addresses.js` 对列表使用 `where: { userId }`；修改、删除、设默认均在操作前检查 `existing.userId === req.user.userId`，不匹配统一返回 404。
- 隔离 API 实测：在 `mowo_b1_test` 注册两名测试用户；用户 B 的地址列表为 0 条，删除用户 A 地址返回 HTTP 404，用户 A 自己删除返回 HTTP 200。
- 前端默认地址、编辑校验和“删除默认地址后自动选最新地址”的浏览器行为仍待人工验收；不会在未知账户上执行。

### B2-B 注销路径审计（2026-09-09）

- `GET /api/v1/account/deactivate/check`、发送验证码、提交申请均重新计算相同阻断项；不能绕过前端直接提交。
- 阻断范围包括：未完结订单/售后、待付款预订单、待审认证、处理中联络、联名作品/收益/结算/合同、投诉、工作人员账号，以及处于 `SUBMITTED`、`REVIEWING`、`OPTIONS_READY`、`CONFIRMED` 等状态的定制申请。
- 申请注销会将账号置为 `PENDING_DELETE`、记录十分钟保护期、撤销全部设备会话并拒绝待上传私有文件；到期处理重新检查阻断项，发现新阻断则恢复为 `ACTIVE` 并标记为阻断，而不是盲目删除。
- 撤销仅接受尚未进入清理阶段的 `REQUESTED/PAUSED` 请求；用户需重新登录后调用撤销接口。文件删除和匿名化发生在到期后，因此本轮不对测试账号自动执行申请。

注销人工验收（仅在你明确说“允许测试注销”后执行）：使用一个没有订单、定制、地址以外业务数据的测试账号，在设置页先查看阻断检查，再提交验证码 `123456` 的申请；确认已退出；重新登录该账号并在设置页撤销。最终应回到 `ACTIVE`，且不触发任何真实资料清理。

### B2-C 私有文件与动画资产隔离（2026-09-09）

- 动画资产列表以 `ownerUserId + ACTIVE + frontDeletedAt=null` 查询；详情、改名、版本追加、复购和软删除均二次检查资产所有者，不匹配统一返回 404。
- 动画版本新增时，提交的每一帧都必须是当前用户的 `READY` 私有文件；同一客户端版本键发生重试时也会再次核对资产与用户，避免跨账号复用幂等结果。
- 私有上传的完成接口以 `fileId + ownerUserId`（匿名联络文件则为独立匿名会话哈希）查询；头像采用同样检查用户、用途和文件状态。受控私有读取会检查所有者或员工授权，普通头像是唯一允许公开读取的例外。
- **动画资产实测：** 在 `mowo_b1_test` 创建最小私人动画资产后，用户 B 的详情读取、改名、删除均返回 HTTP 404；所有者详情读取为 HTTP 200、软删除为 HTTP 200。该测试未上传或读取真实文件。
- **受控文件实测：** 在 `mowo_b1_test` 创建一个属于用户 A 的最小 `CUSTOMIZATION_SOURCE` 私有文件后，用户 B 请求 `/api/upload/presign-get` 返回 HTTP 403（“无权查看该文件”），用户 A 为 HTTP 200。该验证只生成读取地址，不上传或读取真实素材。

### B2-D 自己筛帧草稿边界（2026-09-09）

- 源码：保存草稿前，`/api/customization-requests/draft` 会验证已启用机型、当前账号的 `CUSTOMIZATION_SOURCE` 原素材和当前账号的可选帧；创建时以事务同时写草稿、事件和文件关联。读取与提交均再次核对 `item.userId`。
- 隔离 API 实测：用户 A 创建最小草稿为 HTTP 201、自己读取为 HTTP 200；用户 B 读取和提交该草稿均为 HTTP 403；用户 B 复用 A 的 `clientDraftKey` 为 HTTP 409。测试仅在 `mowo_b1_test` 写入临时机型、文件和草稿，不进入订单或员工队列。
- **完整 API 链路实测：** 使用一份包含一条原素材、一帧已选帧、测试机型与测试 SKU 的隔离草稿：创建为 HTTP 201；提交为 HTTP 200，状态转为 `CONFIRMED`，生成定制编号和一版私有动画；同请求重试为 HTTP 200 且 `reused=true`，动画版本仍为 1。详情事件顺序为 `DRAFT_SAVED`、`ORDER_CHECKOUT_READY`。该接口只表示“可进入结算”，不创建订单、不锁库存也不发起付款。
- 待继续：浏览器真实上传/筛选/选款式回归，以及确认页如何从 `CONFIRMED` 接入交易层的单独审计。

### B2-E 人工筛帧权限与状态机初查（2026-09-09）

- 后台入口由全局 `requiredPermissionForRequest` 映射为 `CUSTOMIZATION_REVIEW`：未携带会话访问 `/api/admin/customization-requests` 实测为 HTTP 401；普通用户不能依靠隐藏前端入口读取任务。客服、生产和负责人可读取；只有 `OWNER`、`PRODUCTION` 可编辑。
- 领取使用条件更新和十分钟锁：同一任务被另一员工持有且锁未过期时返回冲突；心跳、保存草稿、提交帧图均要求当前员工、`REVIEWING` 状态和未过期锁。提交事务会创建版本化筛帧记录、把员工临时帧转交给用户并关联到筛帧结果、替换旧结果、更新申请为 `OPTIONS_READY`，同时写入事件。
- 用户侧读取筛帧结果、接受、申请调整和选 SKU 都再次核对申请所属用户。接受后以事务创建/复用用户动画版本并转为 `FRAME_ACCEPTED`；选择有效 SKU 后转 `CONFIRMED`，只写入“可结算”事件。
- 动态岗位链尚未执行：本机 API 的测试短信 IP 频率保护返回 HTTP 429。不会为了测试修改频率规则或伪造生产会话；待频率窗口恢复后，用隔离库中的测试员工账号按真实登录路径执行领取、锁冲突、提交、接受、调整和选 SKU 回归。

1. 当前本机验收环境已启动：静态页为 `http://localhost:5500/mowo/frontend/pages/index.html`，API 为 `http://localhost:3001`，且 API **只连接**隔离库 `mowo_b1_test`。打开无痕窗口或先清除该站点 Local Storage，访问 `http://localhost:5500/mowo/frontend/pages/my-customizations.html`；应跳到首页并自动打开登录弹窗，地址带有 `auth=1` 和安全的 `redirect` 参数，不能出现 `auth.html` 或 404。
