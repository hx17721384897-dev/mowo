## 1. 状态标签与记录规则

| 标签 | 定义 |
|---|---|
| 可用 | 有正式入口、服务端校验、数据写入、消费者和验证证据。 |
| 可用但有限制 | 主路径可走，但有人工、范围或异常处理限制。 |
| 未完成 | 只有局部实现，不能形成业务闭环。 |
| 新旧冲突 | 多套入口、状态、模型或接口重叠承担同一职责。 |
| 关闭但保留 | 当前不开放，仍有未来业务、数据兼容或追溯价值。 |
| 可归档候选 | 尚未发现正式入口、消费者、数据责任和近期业务价值；本标签不授权删除。 |
| 安全/上线阻断 | B1 邀请真实用户前必须处理。 |
| 待业务确认 | 无法由代码决定，需要负责人确认规则。 |

每条记录均应包含：证据范围、消费者、数据影响、权限/功能开关、测试证据、风险、推荐动作和最后核对日期。没有完成这些字段的条目只能作为线索，不能作为删除或重构依据。
