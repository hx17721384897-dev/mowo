## F. 注销与撤销

1. 使用 `18800009103` 注册并登录，不创建订单、售后、合同或联名记录。
2. 进入“账号设置 -> 账号注销”，阅读影响说明并申请注销。
3. 输入验证码 `123456`，确认申请成功后当前账号自动退出。
4. 立即重新登录该手机号，确认页面显示注销状态和“撤销注销”；重新登录本身不会撤销，必须由用户明确点击“撤销注销”并再次验证身份，成功后账号恢复正常。
5. 再申请一次注销，然后切换到负责人后台“注销任务”，确认能看到 `REQUESTED` 任务。
6. 在保护期内可测试“暂停”和“恢复”；暂停必须分别填写仅员工可见的内部原因和用户可见说明。用户只能看到公开说明，恢复后任务回到待处理状态。
7. “恢复”和“重试”请求没有额外填写内容，页面不得发送空 JSON 请求体，也不应出现 `Body cannot be empty`。

通过标准：提交后全部会话退出；10 分钟保护期内用户主动撤销并重新验证身份后可恢复；后台能观察、暂停和恢复任务；内部原因不会展示给用户。
