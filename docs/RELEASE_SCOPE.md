## 发布阶段

| 阶段 | 目标 | 真实收款与用户范围 |
|---|---|---|
| B 邀请测试 | 跑通介绍、上传、审核、确认订单以及内部处理流程 | 不强制真实在线收款；少量测试可另行采用合规的企业商户人工收款 |
| C 小规模真实交易 | 跑通微信小程序真实支付、退款、生产、物流和售后 | 仅小范围用户；需先完成支付、安全、备份和对账验收 |
| D 公开上线 | 对公众持续提供服务并承载增长 | 完成容量、监控、应急、法律文本和运营责任验收后进入 |

项目当前不邀请真实用户；先按 Vue 重构计划整理出可维护的基础版本，再另行决定何时进入 B。不能把未来 C/D 的能力同时塞进首发。

## 首发用户流程

1. 用户在 Web 浏览产品和已审核联名商品，无需登录。
2. 用户上传定制视频并查看筛选结果和标准 SKU 价格，无需登录；保存云端草稿或提交订单时使用短信验证码登录。
3. 用户可自己筛帧，也可请员工异步筛帧；人工筛帧是画面处理服务，不是私人定制内容审核。
4. 用户从可制作的标准款式和固定最终价格中确认，系统生成订单或受控订单入口。
5. Web 不直接收款；用户通过不可猜测、短期有效的小程序码进入微信小程序。
6. 小程序完成微信身份、手机号绑定、订单确认，并在进入 C 阶段后使用微信官方支付。
7. 用户在平台查看订单、发货和售后状态；企业微信只负责沟通与发送受控订单入口，不代替账号、订单或付款数据库。

## 文件与数据边界

- 定制视频/原图、联名原帧/帧包、联络作品集/简历、合同附件是不同业务数据，必须分别授权和设置生命周期。
- 作品集只接受 JPG、PNG、PDF，单文件不超过 20MB；简历只接受 PDF，不超过 10MB；公开联络首发拒绝 Word、ZIP、PSD、AI 和可执行文件。
- 合同只允许授权员工在后台上传 PDF 或图片，不经过公开联络表单。
- 未合作且不再跟进的作品集、简历和联络附件，在最后一次有效联系后 6 个月删除；进入正式合作、录用或争议的材料转对应受控记录。
- 联名下架后关闭公开访问；历史买家只看成交快照和售后信息，不读取原帧；受控私有素材访问需留痕。
- 正式合同和财务记录不可物理删除，只能作废、归档或冲正；无资金和履约关联的未生效草稿可按权限删除。

## 当前发布事实

当前代码仍是未上线的产品原型，不是可直接公开发布的企业生产版本。隔离空库迁移、合成数据回归和本地备份恢复已经可重复；但小程序核心页面和会话续期、真实支付验签、正式附件安全、CI/预发、线上备份、监控告警、容量和法律文本仍未达到公开上线门槛。发布阻断项见 `modules/operations-quality.md`。

2026-09-14 已完成 R1-B：社区、线上创作者财务、牛量/推广、模拟认证和创作者自助旧实现已从运行代码与无消费者数据结构中物理删除，不再依赖隐藏按钮或可重开的服务端开关。联名作品展示、购物、定制上传、人工合作、后台合同台账和内部外部订单导入保持保留并通过回归。用户协议与隐私政策仍只是测试草案，正式法律文本尚未完成审查。

现有页面中已经出现支付宝、全球配送、一年保修、退换和退款时效等具体说法，项目负责人暂不能确认其业务依据，可能只是页面设计占位。它们不因已经写在页面上就成为已批准规则；保留原文供追溯，B1 前应标记、隐藏或改成不误导的测试文案，C 前再发布经确认的正式消费者政策。
