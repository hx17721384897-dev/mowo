## 已确认的外部订单边界

V4-E3 重新核对后确认，旧实现只写旧 `CustomizeOrder`，并未完成正式 `SalesOrder -> Item -> PU` 映射；数量固定为 1、渠道客户借用操作员身份，且淘宝 CSV 列名与编码均属于未经真实样表确认的假设。因此当前只保留负责人/生产岗位可见的 Vue 入口，上传、手工录入、异常补全和 SKU 映射 API 均由服务端关闭，旧页面及路由源码删除。历史数据表与记录保留；未来必须取得真实脱敏样表并重新确认数量、归属、履约、库存与幂等契约后开发，不能重新开启旧实现。
