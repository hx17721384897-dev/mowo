# 材料包款生产全流程手工测试

> 制定日期：2026-08-29  
> 范围：从用户创建订单、模拟付款，到批次、打印/领料、配对、装箱和确认发货；暂不测试售后。  
> 本轮规模：3 个总订单 `SO`、5 个单件生产任务 `PU`、1 个生产批次 `PB`。

## 一、测试前限制

- 本轮只选择“标准款、5x5cm、12 帧”。这组已配置有效模板 `12张.docx`。
- 可选三种 SKU：椴木板原色、椴木板胡桃色、亚克力透明。
- 不选择 8x8cm 16/24 帧：当前已经配置打印组，但还没有上传有效 Word 模板，导出生产资料会被阻止。
- 每完成一个订单的模拟付款，再创建下一个订单，避免三个测试订单被购物车合并成一个 `SO`。
- 地址、手机号和快递单号仅用于本地测试，禁止交给真实快递公司。
- 数据库已有其他未完成订单；后续操作只认本轮记录下来的 3 个 `SO` 和新建 `PB`。

## 三、创建生产批次

1. 进入“生产 → 生产批次”，点击“创建生产批次”。
2. 只勾选本轮 `SO-A`、`SO-B`、`SO-C`，不要选择历史订单。
3. 确认创建，并记录：`PB：________________`。
4. 预期：3 个订单全部从“已付款”进入“待处理”；批次详情显示 3 个总订单、5 个生产件。

## 四、地址与虚拟快递面单

1. 进入“生产 → 全部订单 → 待处理”，在本轮 `PB` 点击“导出本批次地址”。
2. 下载的 CSV 应有 3 行总订单地址，不应按 5 个生产件重复成 5 行。
3. 预期：3 个订单进入“处理中”。
4. 为三行订单填写以下面单，不要填错 `SO`：

| 订单 | 快递公司 | 测试快递单号 |
|---|---|---|
| SO-A | 顺丰速运 | SFTEST202608290001 |
| SO-B | 中通快递 | ZTTEST202608290002 |
| SO-C | 京东物流 | JDTEST202608290003 |

5. 点击“确认本批次面单”。预期：3 个订单进入“待生产”。

## 五、导出生产资料并记录 FP

1. 进入“生产 → 全部订单 → 待生产”，点击“导出生产资料并开工”。
2. 下载 ZIP，检查至少包含可打印 Word、帧包标签 CSV、材料需求 CSV。
3. 预期：3 个订单进入“生产中”，系统为 5 个 `PU` 各生成一个唯一 `FP`。
4. 在“生产中”页面或帧包标签 CSV 抄录真实编码：

| 归属 | 规格 | 实际 FP 编码 |
|---|---|---|
| SO-A | 椴木板原色 ×1 | `________________` |
| SO-B-1 | 椴木板胡桃色 ×1 | `________________` |
| SO-B-2 | 亚克力透明 ×1 | `________________` |
| SO-C-1 | 椴木板原色，第 1 件 | `________________` |
| SO-C-2 | 椴木板原色，第 2 件 | `________________` |

`FP` 不能提前虚构。导出完成后，把 `PB` 或三个 `SO` 发给 AI，也可以直接查询并生成准确扫码顺序。

## 六、帧包完成岗位（蓝色）

1. 进入“生产 → 扫码作业 → 帧包完成”。
2. 不点击输入框，依次扫描上表 5 个真实 `FP`。
3. 每次应显示对应 `PU` 和 SKU，并提示帧包已完成。
4. 可把第一个 `FP` 再扫一次，预期提示此前已经完成，不重复增加进度。
5. 作业总览预期：帧包完成 `5/5`；领料、配对、装箱仍保持 `0/5`。

## 七、材料领用岗位（橙色）

先选择本轮 `PB`，再按下表扫码和填写数量：

| 材料 SKU | 可扫码批次码 | 领取数量 | 对应订单 |
|---|---|---:|---|
| 5x5cm 12帧 椴木板原色 | `LEGACY-KIT-09698D2B` | 3 | SO-A ×1、SO-C ×2 |
| 5x5cm 12帧 椴木板胡桃色 | `LEGACY-KIT-F8DE0982` | 1 | SO-B-1 |
| 5x5cm 12帧 亚克力透明 | `LEGACY-KIT-7BFD6366` | 1 | SO-B-2 |

每一行操作方式：直接扫描批次码 → 检查页面显示的规格 → 填写领取数量 → 点击“确认领用”。

预期：只产生预留，不立即扣减材料包实物库存；作业总览显示材料已领 `5/5`，配对仍为 `0/5`。

## 八、单件配对岗位（青色）

页面会持续使用当前材料来源，换 SKU 时必须先扫描新的材料批次码。

1. 扫 `LEGACY-KIT-09698D2B`，再依次扫 SO-A 的 1 个 `FP` 和 SO-C 的 2 个 `FP`。
2. 扫 `LEGACY-KIT-F8DE0982`，再扫 SO-B-1 的胡桃色 `FP`。
3. 扫 `LEGACY-KIT-7BFD6366`，再扫 SO-B-2 的亚克力 `FP`。
4. 每成功配对一件，正式扣减该材料批次一套，并记录该 `PU` 使用的材料来源。
5. 作业总览预期：配对 `5/5`，装箱仍为 `0/5`。

可选防错测试：激活椴木板原色材料后，先扫 SO-B 的亚克力 `FP`，应提示 SKU 不一致且不扣库存；随后切换正确材料码继续。

## 九、装箱与发货岗位（绿色）

### SO-A 单件订单

1. 扫 `SFTEST202608290001`。
2. 扫 SO-A 的唯一 `FP`。
3. 页面应提示整单配齐，可以确认发货；点击“确认发货”。

### SO-B 两种商品订单

1. 扫 `ZTTEST202608290002`。
2. 先只扫 SO-B-1 的 `FP`，页面应提示仍有产品未齐，并保存在待齐套区。
3. 再扫 SO-B-2 的 `FP`，页面才允许确认发货。
4. 点击“确认发货”。

### SO-C 同 SKU 两件订单

1. 扫 `JDTEST202608290003`。
2. 依次扫 SO-C-1、SO-C-2 两个不同 `FP`。
3. 只扫一件时不得发货；两件齐全后点击“确认发货”。

## 十、最终验收

- “全部订单 → 已发货”能查到 3 个 `SO`，快递公司和测试单号正确。
- 本轮 `PB` 状态为已完成；批次显示帧包、材料、配对、装箱均为 `5/5`。
- 三个总订单各自只发货一次；SO-B 和 SO-C 不允许缺一件发货。
- 五个 `FP` 均为已发货，不能再次配对或装入别的快递单。
- 材料批次最终实际消耗：原色 3、胡桃色 1、亚克力 1；本轮开始时三者均为 50 且无预留，正常结束后应分别为 47、49、49。
- 操作日志能查到帧包完成、材料领用、五次配对和三次发货记录。

任一步骤与预期不一致时先停止，不要为了继续测试而直接修改数据库；记录当前 `SO/PB/FP`、页面提示和控制台/网络请求信息后定位。
