# Web 定制流程首批验收清单

> 范围：2026-08-20 的“提交与后台接收”首批。推荐方案、补素材、最终价格和订单生成不在本次验收范围。

## 前置准备

1. 后端在 `content-service` 目录执行 `npm start`，看到监听 `127.0.0.1:3001`。
2. 静态网页使用当前 `5500` 服务。
3. 准备一个普通测试账号和负责人账号 `17721384897`。
4. 准备一张普通 PNG/JPG；视频测试可另备小于 200 MB 的 MP4。
5. 打开 [定制入口](http://127.0.0.1:5500/mowo/frontend/pages/customize-start.html)。不要使用 `file:///` 打开。

## 人工筛选入口

- 选择一个款式，进入上传页；常见电脑窗口中标题、左右两个入口和各自操作按钮应一次显示，无需先向下滚动。
- “返回选型号”位于顶部步骤栏；上传页底部不再重复显示私密保存和制作审核说明。
- 在“请工作人员帮我筛选”上传素材，看到异步处理提示。
- 未登录提交时应先弹出登录，登录后继续提交。
- 正式提交前应再次提示将进入人工筛选和制作可行性审核；取消后不得上传或创建申请。
- 提交成功后进入“我的定制”，出现 `DZ-日期-尾码` 编号和“等待处理”。
- 使用另一个普通账号，不能看到前一个账号的定制记录。

## 自己筛选入口

- 上传素材，完成裁剪/抽帧/勾选，预览不需要先登录。
- 点击下一步时未登录应弹出登录；登录后继续保存。
- 确认页选择一个标准规格，点击“提交制作审核”。
- 回到“我的定制”后看到正式 `DZ` 编号；提交前的草稿不应提前获得公开编号。
- 页面不应再提供绕过审核的直接加入购物车按钮。

## 后台接收

- 使用负责人账号打开 [定制审核](http://127.0.0.1:5500/mowo/frontend/pages/admin-customization-requests.html)。
- 列表能看到刚提交的两条申请，能按状态、方式和编号筛选。
- 详情仅显示用户昵称和手机号后四位。
- 原素材/选中帧可通过临时链接预览；普通用户和合作运营无权打开该后台接口。
- 本批后台只负责接收查看，没有处理按钮属于预期，不是页面故障。

## 自动检查

在 `content-service` 执行：

```powershell
npm run check
npm run check:customization-flow
npm run check:staff-security
npm run check:private-files
npm run check:account-deletion
npm run check:launch-safety
```

## 延后验证

- 工作人员推荐其他动画或多个适配款式。
- 用户补素材、确认方案和最终固定价格。
- 有已确认定制时生成订单、扫码关联小程序和付款。
- 有真实订单时账号注销的端到端联动。
- 正式 OSS、杀毒扫描、备份恢复、容量和并发压测。
