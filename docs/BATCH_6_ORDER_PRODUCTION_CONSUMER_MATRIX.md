# B6 新旧订单、批次、扫码与生产消费者清单

> 最后核对：2026-09-10
> 用途：说明每组订单/生产入口由谁调用、是否仍属当前流程，以及旧入口在删除前应如何处理。本文只记录代码事实和当前决定，不授权删除页面、路由、模型或历史数据。

## 1. 当前正式链路

| 业务能力 | 正式服务端入口 | 当前消费者 | 结论 |
|---|---|---|---|
| 用户订单列表与详情 | `/api/orders`、`/api/orders/:id` | `orders.html`、`order-detail.html`、订单结构检查 | 当前用户交易主链，保留。 |
| 生产批次 | `/api/admin/production-batches*` | `admin-production-batches.html`、Vue `/app/admin/orders` 跳转、生产批次专项 | 当前后台批次主链，保留。 |
| 生产订单与状态推进 | `/api/admin/production-workflow/orders*` | Vue `/app/admin/orders`、`admin-production-batches.html`、生产工作流专项 | 当前生产状态主链，保留。 |
| 批次生产动作 | `/api/admin/production-workflow/batches*` | 生产批次页、生产工作流与资料专项 | 当前领料、帧包、配对、装箱等主链，保留。 |
| 扫码工作台 | `/api/admin/production-workflow/scan*` | `production-scan-workbench.html`、扫码安全/UI 专项 | 当前扫码主链，保留。 |
| 打印、帧图和生产资料 | `/api/admin/print-production*`、`/api/admin/frame-*`、生产资料相关入口 | 对应后台页及 5 组专项脚本 | 当前生产辅助链，保留。 |

`CustomizeOrder` 这个 Prisma 模型虽然名称来自旧版本，但当前正式 `SalesOrderItem.productionTasks` 仍把它作为 PU/单件生产任务使用。因此不能仅凭模型名称删除或迁移它；本轮关闭的是无消费者的旧 HTTP 入口，不是删除仍被正式链路引用的数据模型。

## 2. 已关闭但尚未删除的旧入口

这些入口没有发现当前正式页面或检查脚本消费者。服务端保留源码和路由注册，以便回退与进一步核对，但已在统一前置处理器中对已登录请求返回 HTTP `410` 和错误码 `LEGACY_ENDPOINT_CLOSED`，防止新功能误接回旧链路。

| 旧入口组 | 旧数据/行为 | 当前处理 |
|---|---|---|
| `/api/customize-orders*` | 直接创建、读取和推进旧定制订单 | 4 个代表路径已关闭。 |
| `/api/admin/stats`、`/api/admin/orders*` | 旧后台统计、订单列表/详情/状态与地址导出 | 已关闭。 |
| `/api/admin/production`、`/api/admin/production/orders` | 旧生产汇总和生产订单 | 已关闭。 |
| 旧批次写入口 | 创建预览、创建批次、统计、按 SKU 完成/报废 | 已关闭。 |
| `/api/admin/scan*` | 旧扫码实现 | 已关闭，正式扫码工作台不受影响。 |
| `/api/admin/auth-codes*` | 旧验证码生成和管理 | 已关闭。 |

静态边界检查当前覆盖 29 个应关闭的代表请求和 8 个必须保留的代表请求；员工隔离运行回归同时验证旧入口为 410、正式生产工作流仍为 200、未登录后台请求仍先按 401 拒绝。

## 3. 仍保留的旧入口与原因

| 入口/能力 | 已发现消费者或业务依赖 | 当前决定 | 后续需要确认 |
|---|---|---|---|
| `GET /api/admin/batches`、`GET /api/admin/batches/:id/progress` | `production-inventory.html` | 暂不关闭；页面虽未出现在主后台侧栏，但它是实际代码消费者。 | 决定页面继续保留并迁入正式生产批次链，还是未来连同旧只读入口一起下线。涉及删除时再次确认。 |
| `/api/admin/aftersales*` | 未发现当前后台页面消费者；正式订单仍能产生 `AftersaleRequest` | 暂不关闭；否则会形成“用户能申请、后台无人处理”的功能断点。 | 决定补最小后台售后消费者，还是在本地基础版本明确延期并关闭用户申请入口。 |
| `_legacy/admin-production.html` | 仅归档引用部分旧生产入口 | 保留为历史取证，不视为正式消费者，也不据此重新开放接口。 | B7 核对归档说明和不可达性。 |

## 4. 删除前置条件

任何旧页面、路由、模型或历史字段的物理删除都必须同时满足：

1. 全仓库消费者搜索为空，或消费者已经迁移并回归通过；
2. 说明历史数据是否仍需读取、如何迁移以及如何回退；
3. 正式链路有等价失败态、权限和审计覆盖；
4. 单独列出删除对象并取得项目负责人确认；
5. 删除后运行隔离库生产专项、完整自动检查和对应浏览器验收。

## 5. 本轮验证证据

2026-09-10 已在仅允许连接 `mowo_b1_test` 的一次性本地 API 上完成以下 9 项生产专项：生产工作流、扫码安全、生产批次、打印排产、帧图库、帧图制作、帧图导入、生产资料、扫码 UI。扫码安全夹具自行创建并清理，未依赖开发库历史数据；本轮未修改 `mowo_db`。
