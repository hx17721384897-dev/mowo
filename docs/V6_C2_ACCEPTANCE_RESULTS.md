## 1. 自动证据

### 1.1 页面与浏览器

桌面 Chromium 和 Pixel 7 两个项目共 48/48 通过，覆盖：

- 官网导航、跨页几何稳定、登录弹窗、头像和用户菜单、移动导航；
- 首页正常数据与空态；
- 联络六类表单、单次提交、附件边界、非 JSON 错误和移动布局；
- 联名列表、详情深链接、破损媒体降级、关闭结算交接；
- 设置页与共享地址组件；
- 我的定制和我的动画的筛选、时间线、版本及安全写操作。

### 1.2 真实隔离库

真实 API、浏览器和数据库联合检查全部通过：

- 有效会话进入受保护页面，退出后受保护路由重新要求登录；
- 首页、关于、产品页导航字体族和非当前项字重一致；
- 头像裁剪上传并被资料采用，任意头像 URL 和跨用户采用被拒绝；
- 资料保存、短信换号导致旧会话失效、重新登录、首个默认地址、地址校验和编辑正确；
- 联名公开列表只返回正式上架版本，价格来自正式销售配置，内部审核人、分成、下架原因和内部价格不泄露；
- 联名加购保存展示快照，单项/合并数量上限、隐藏作品、错误 SKU、暂停后购物车失效及结算阻断均由服务端执行；
- 私有文件覆盖六类岗位、跨用户、未绑定文件、头像公开边界、售后证据、创作者帧、匿名简历及内容类型校验。

### 1.3 日志与清理

- Fastify 运行日志敏感模式匹配：0。
- 未解释的 HTTP 500、Prisma 错误：0；`api.err.log` 为空。
- 脱敏门禁确认密码、验证码、Authorization、Cookie、完整手机号、邮箱、地址、物流号、对象 Key 和签名 URL 不写入操作摘要。

- 本切片没有调用定制草稿创建接口；未产生重复草稿、订单、预订单或生产批次。

## 2. 负责人需要执行的人工验收

### 准备

1. 不需要停止或重新运行服务；当前地址为 `http://127.0.0.1:4173/app/`。
2. 浏览器按 `Ctrl+F5` 强制刷新一次。
3. 使用现有负责人账号登录。本轮不要修改手机号、密码，不提交注销，也不要保存测试地址；这些写操作已经由一次性账号自动验证并清理。
4. 每发现一处问题，记录“步骤编号、页面地址、看到的现象”，最好附截图；不要重复点击提交按钮。

### C2-M01：首页和统一导航

1. 打开 `http://127.0.0.1:4173/app/`。
2. 观察 Logo、主导航、登录/头像区域和首屏，不应出现错位、乱码或横向滚动条。
3. 依次点击“关于我们 → 产品介绍 → 常见问题 → 联系我们 → 返回首页”。
4. 每次切换时观察导航栏高度、Logo 位置和右侧用户区域，不应上下抖动或突然改变字体。
5. 将浏览器宽度缩到约 900px，再缩到手机宽度约 390px；打开移动菜单并逐项跳转，页面不得横向溢出。

### C2-M02：登录、头像和用户菜单

1. 未登录时点击右上角登录入口，确认仍是原设计的登录弹窗，不是重新设计的页面。
2. 点击弹窗内用户协议、隐私政策，再返回；弹窗不能重复叠加。
3. 登录现有负责人账号。
4. 确认右上角出现头像；点击头像，菜单应包含个人设置、我的定制、我的动画、我的订单及后台入口。
5. 点击页面空白处，菜单应关闭；再次打开后选择“个人设置”。本轮先不要退出登录，以便继续后续步骤。

### C2-M03：官网静态页和 FAQ

1. 分别直接打开：
   - `http://127.0.0.1:4173/app/about`
   - `http://127.0.0.1:4173/app/products`
   - `http://127.0.0.1:4173/app/faq`
   - `http://127.0.0.1:4173/app/legal/terms`
   - `http://127.0.0.1:4173/app/legal/privacy`
2. FAQ 搜索一个能命中的词，再输入不存在的词；结果和空态应清晰，输入不应使页面跳动。
3. 法律页必须明确显示当前文本状态，不能冒充已正式生效的最终法律文本。

### C2-M04：联络页面

1. 打开 `http://127.0.0.1:4173/app/contact`。
2. 依次打开六类联络入口，检查标题、字段和关闭按钮。
3. 在其中一个表单输入几段文字，但不要提交；关闭后焦点应回到原入口，页面不得执行文字中的 HTML。
4. 手机宽度下再次打开表单，底部提交区应可见且页面不得横向滚动。

### C2-M05：联名货架

1. 打开 `http://127.0.0.1:4173/app/showcase`。
2. 如果当前隔离库有上架作品：进入详情、切换规格、查看价格和媒体，再返回列表；不要进入结算。
3. 如果显示空态：确认文案是“暂无作品”类真实空态，不能生成虚构商品卡片；把空态截图发给我即可。
4. 破损或缺失图片应显示降级占位，不应把内部对象 Key、审核人、分成比例或下架原因展示出来。

### C2-M06：账户设置和地址复用

1. 打开 `http://127.0.0.1:4173/app/account/settings`。
2. 检查头像、基本资料、安全设置、收货地址和账号注销区域是否都存在，版式应保持原设计。
3. 打开头像裁剪窗口后取消，不上传文件。
4. 打开收货地址；点击“新增地址”，检查姓名、手机号、省市区、详细地址、标签和默认地址选项，然后取消。
5. 若已有地址，打开编辑窗口确认与新增地址使用同一套字段和样式，然后取消，不保存。
6. 不执行换号、改密和注销，只检查入口、说明和危险操作确认结构。

### C2-M07：我的定制和我的动画

1. 打开 `http://127.0.0.1:4173/app/account/customizations`。
2. 若有记录，切换状态筛选、展开一条时间线；若为空，检查空态和“开始定制”入口。
3. 打开 `http://127.0.0.1:4173/app/account/animations`。
4. 若有素材，展开版本和操作区但不要删除或保存新版本；若为空，检查空态。
5. 刷新两个页面各一次，刷新本身不得自动创建草稿或弹出成功提示。

### C2-M08：结束检查

1. 点击头像菜单中的退出登录。
2. 直接打开 `http://127.0.0.1:4173/app/account/settings`。
3. 应回到首页并自动打开登录入口，同时保留安全回跳；不应短暂显示账户数据。
4. 把以下结果回复给维护者：`M01～M08 是否通过`，以及所有失败步骤的截图和说明。

人工验收完成后，维护者还需再次只读检查运行日志、操作日志和业务表；负责人不需要自行查看数据库。

## 3. 当前结论

C2 的自动逻辑、安全、权限、数据库与清理证据通过；页面主观视觉和真实现有数据展示仍等待负责人按 M01～M08 确认。在该确认之前，不把 V6-C2 标记为完全关闭，也不进入 C3 的有状态定制/交易人工验收。
