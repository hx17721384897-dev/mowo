# V1c 联络表单与附件迁移记录

> 状态：2026-09-16 自动验收完成，等待负责人视觉确认与旧页删除。当前阶段只面向本地隔离测试，不代表可以公开接收真实隐私资料。

## 1. 目标与边界

Vue 接管 `/app/contact`，保留画师/IP、线下渠道、媒体/博主、加入团队、反馈、厂家六类联络入口。六类均允许匿名提交；登录用户由服务端依据已验证会话绑定账号，前端不发送或声明用户 ID。

V1c 不迁移后台联络管理，不新增社区、创作者自助、线上财务、牛量或支付能力。旧 `contact.html` 在 Vue 页面完成自动与负责人视觉验收前只作为固定视觉事实源；验收后物理删除，不长期双轨。

## 2. 迁移前证据与决策

- 正式提交接口为 `POST /api/contact`，服务端允许六类枚举并执行数据库 IP 小时限流、反垃圾、可选会话认证和附件归属绑定。
- 匿名附件使用当前浏览器会话生成的高熵 `X-Upload-Session`；服务端只接受同一匿名会话创建、已完成校验、尚未绑定且用途匹配的私有文件。
- 画师作品集最多 6 个文件，单文件 20 MiB；只允许 JPG、PNG、PDF。求职简历只允许 1 个 PDF，单文件 10 MiB。旧实现接受 GIF、WEBP、ZIP、DOC/DOCX、PSD/AI 的行为与已确认产品规则冲突，本批同时收紧前端与服务端。
- 线下渠道、媒体、反馈和厂家不接收附件，只提交结构化文字和可选 HTTP/HTTPS 外部链接。
- 公开接口的 `extra` 必须按联络类型执行字段、类型、长度和 URL 协议白名单；不能继续保存任意对象并依赖前端自律。
- 旧页关于必须登录、固定 3/5 个工作日回复、100% 回复、品牌背书等陈述与当前事实不一致。迁移保持区块、尺寸和主要交互，但用可证实的匿名提交、人工评估、受控附件和隐私说明替换这些承诺。

## 3. 共享组件决策

公共导航继续复用 `PublicHeader`，联络页不复制导航。六类弹窗具有相同外壳、焦点管理、错误、提交和成功状态，因此在联络模块内使用一个数据驱动表单弹窗；字段和文案差异通过明确配置表达，不把联络专属表单提前提升为全站通用组件。页面页脚保持旧联络页自己的视觉规格。

任何与其他页面同名但结构、断点或交互不同的元素，必须先按 `VUE_FRONTEND_REFACTOR_PLAN.md` 的共享组件决策门比较；无法判断时先由负责人确认。

## 4. 安全门禁

- 上传申请、二进制上传、完成确认、联络提交任一步失败都显示受控错误；不在页面、控制台或记录中输出 Token、上传会话、对象 key、签名 URL 或响应正文。
- 向签名上传地址发送文件时不携带 Cookie 或 Authorization；完成确认只允许回到配置的 API Origin 和 `/api/upload/files/:id/complete` 路径。
- 文件扩展名、声明 MIME、大小和真实文件头由服务端共同校验；前端校验只用于尽早反馈。
- 重复点击提交必须被锁定；失败后允许明确重试，成功后不自动再次提交。
- 弹窗具备真实 `dialog` 语义、关闭后焦点回到触发卡片、打开时聚焦、Escape/遮罩关闭和页面滚动锁定。
- 当前尚无已选定的人机验证供应商。公网开放匿名联络前必须接入服务端可验证的人机挑战，并完成可信代理、跨实例限流、监控与压力测试；在此之前不能把 V1c 标记为公网发布就绪。

## 5. 验收与删除门槛

1. 固定旧页面事实源，对相同数据和 1440×900、390×844 视口生成新旧截图。
2. 覆盖六类弹窗、必填校验、成功、服务端失败、非 JSON、网络失败、重复提交、匿名附件、文件拒绝、Escape、焦点恢复和移动端无横向溢出。
3. 后端覆盖 `extra` 白名单、URL 协议、附件数量/用途/归属，以及已禁止文件类型的直接 API 绕过。
4. Vue 全量门禁与相关 B7 后端回归通过。
5. 负责人确认视觉与交互后，删除旧 `contact.html`，更新所有旧链接、部署映射和文档；每个正式联络流程只保留 Vue 入口。
