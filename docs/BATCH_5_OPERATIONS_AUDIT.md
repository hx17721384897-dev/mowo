## 2. 岗位模型事实与当前风险

服务端的唯一岗位枚举在 `content-service/src/lib/permissions.js`：负责人（OWNER）、运营客服（CUSTOMER_SERVICE）、生产人员（PRODUCTION）、合作运营（COLLAB_OPS）。`content-service/src/index.js` 已对能够映射到后台权限的请求执行统一鉴权，并记录 `request.staffPermission` 供拒绝审计使用。

| 编号 | 事实 | 风险判断 | 处理状态 |
|---|---|---|---|
| B5-001 | 旧路由仍广泛调用 `fastify.requireRole(1/2/3)`，新入口使用 `requiredPermissionForRequest()` 与岗位权限表。 | **P0 可维护性风险：** 两套模型目前叠加；岗位表变更后，旧数字校验容易产生误放行或误拒绝。 | 进行中：按路由逐项建立权限契约，之后移除重复校验或改为命名权限校验。 |
| B5-002 | `COLLAB_OPS` 为便于兼容被映射为数字 role 2，但它不等于客服。 | **P0 回归风险：** 任何缺失全局路径映射而仅依赖 `requireRole(2)` 的新路由，都可能让合作运营访问客服能力。 | 已将此场景加入员工权限回归检查；待完整路由清单审计。 |
| B5-003 | `admin-contact.js` 的更新/删除/IP 封禁有路由级数字角色校验；全局映射将其归为 CONTACT。 | 现状由全局权限表先拦截，尚未证实越权；负责人专属动作仍应保留明确命名权限而非数字 3。 | 待权限契约改造。 |
| B5-004 | 合同、结算记录、联名运营页面仍存在，但创作者自助、创作者财务和牛量不属于首发。 | **P0 产品边界风险：** 管理后台数据录入功能不等于可对外运营/结算能力。 | 保留源码、服务端 feature gate 继续关闭财务/牛量/推广；待核对所有入口。 |
| B5-005 | 多个 `admin-*.html` 仍各自硬编码 `localhost:3001` 或 `127.0.0.1:3001`；`admin-contact.html` 是固定 `/api` 写法。 | **P1 部署准备风险：** 本机可用不代表反向代理、受邀环境或非默认端口可用。 | 记录；统一运行时 API Origin 改造待后台页面按风险分组处理，不在本轮盲量替换。 |
| B5-006 | 员工权限回归脚本会创建用户、岗位、注销任务和审计日志。 | **P0 测试安全风险：** 不应允许写入 `mowo_db`。 | 本轮已加入 `mowo_b1_test` 强制保护；待在一次性 3002 服务上执行。 |

## 3. 已实施记录（2026-09-09）

- `content-service/scripts/check-staff-security.mjs` 现必须通过 `requireIsolatedTestDatabase()`；目标数据库不是隔离 `mowo_b1_test` 即拒绝运行。
- 回归范围新增：合作运营和生产人员不得读取联络留言；客服不得删除联络留言。测试使用不存在 ID，仅验证权限拦截，不删除任何真实或测试留言。
- 联名后台此前会在统一鉴权后再次手工解码 JWT 并覆盖 `req.user`。现已改为 `PERMISSION.COLLAB` 的命名权限校验，处理器不再可能读到 Token 内的历史岗位。新增回归：合作运营可查看联名审核队列，客服/生产人员被拒绝。
- 本轮仅更新测试边界与审计记录，未删除后台页面、合同或联名数据模型。
