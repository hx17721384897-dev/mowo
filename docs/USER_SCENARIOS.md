## 联名作品管理（Vue `/app/admin/collab-works`）

> V4-C 更新（2026-09-29）：旧 `admin-collab-works.html` 已删除并由 Vue 唯一接管。首发合作暂停、终止和责任判断在线下完成，因此下文由创作者在线发起的动作是历史需求；仍有效且必须在真实交易开放前解决的是“下架后停止新订单、已有订单继续履约、预存库存如何处置”的交易规则。

### 背景：库存模型

联名产品存在两种库存模式：

| 模式 | 触发条件 | 发货时效 | 资金要求 |
|------|---------|---------|---------|
| **按需生产** | 无预存库存 | 一周内发货 | 无 |
| **预存库存** | 创作者/平台提前设置库存，创作者需缴纳抵押金 | 2-3天发货 | 创作者缴纳抵押金，平台生产后形成库存 |

库存可见性：创作者可在自己的后台看到该款的库存数量。

---

### 场景 A：无库存 + 无未完成订单 → 申请下架

- **触发**：创作者在创作者中心点击"下架"
- **需求**：立即下架，不影响任何人
- **系统响应**：直接下架，作品从 showcase 消失，状态变为"已下架"
- **实现状态**：⬜ 待实现

---

### 场景 B：无库存 + 有未完成订单 → 申请下架

- **触发**：创作者申请下架，但仍有订单处于生产/发货流程中
- **需求**：创作者希望下架，平台保证已有订单正常完成
- **系统响应**：
  1. 弹出提示：「该款目前有 X 个未完成订单，下架后我们仍会完成这些订单」
  2. 创作者确认后立即下架（showcase 下线，不接受新订单）
  3. 已有订单按正常流程履约完成
- **实现状态**：⬜ 待实现

### 场景 C：有预存库存 + 申请下架（核心复杂场景）

- **触发**：创作者申请下架，但仍有未售出的预存实物库存
- **关键分歧**：创作者下架目的是**临时**还是**永久**？

#### C1 — 临时下架（暂停销售）
- 创作者原因：调整价格、修改素材、节假日暂停等
- **需求**：暂停接单，但不放弃产品，库存继续保管
- **系统响应**：
  1. 作品从 showcase 隐藏，不接受新订单
  2. 库存冻结保管，不收违约金
  3. 创作者可随时"重新上架"，无需重新审核
  4. ⚠️ 待确认：是否设置临时下架最长时限（如 90 天）？超时后系统如何处理？
- **实现状态**：⬜ 待实现（临时/永久区分逻辑待确认）

#### C2 — 永久下架（有库存）
- 创作者原因：终止合作、停产该款等
- **需求**：彻底下架，不再销售
- **系统响应**：
  1. 弹出提示，展示：剩余库存件数 + 预计违约金金额 + 退还押金金额
  2. 创作者确认后执行下架，违约金从押金中扣除，差额退还
  3. 剩余库存归平台处置（回收零件复用或折价清仓），创作者可通过正常零售渠道购买
- **违约金公式（已确认）**：
  ```
  违约金 = 押金 × 时间系数 × 剩余库存比例
  退还押金 = 押金 - 违约金
  ```
  时间系数（可在管理后台配置）：
  - 0–30 天：70%
  - 31–90 天：50%
  - 91–180 天：30%
  - 180 天以上：15%
  剩余库存比例 = 剩余件数 ÷ 原始件数
- **押金分档（可在管理后台配置）**：
  - 10件→¥500 / 20件→¥800 / 50件→¥1800 / 100件→¥3200
  - 押金金额由平台自主定价，不从生产成本推导，成本对创作者不透明
- **不单独提供买回通道**：创作者若需要产品，通过正常零售下单购买
- **实现状态**：⬜ 待实现

#### C3 — 暂停销售超期自动执行违约
- 超期分阶段通知（天数均可在管理后台配置，默认90天上限）：
  - 第 60 天：站内通知 + 短信「您的产品已暂停 60 天，请在 30 天内决定恢复或下架」
  - 第 85 天：紧急通知「还有 5 天，逾期将按违约金处理」
  - 第 90 天：系统自动执行
    - 无库存 → 直接永久下架，无违约金
    - 有库存 → 扣除违约金，库存移交平台，永久下架
- 时间计算：从首次上架日起累计（含暂停期），不因重新上架而重置
- **实现状态**：⬜ 待实现

### 场景 D：平台主动下架（质量/内容问题）

- **触发**：平台发现产品质量缺陷、动画内容违规、IP 侵权等
- **需求**：立即停止销售，视严重程度决定是否中止在途订单
- **系统响应**：
  1. 管理员直接操作下架，填写下架原因（内部记录）
  2. 选择是否通知创作者（原因可选择是否透露）
  3. 严重质量问题：创作者可申请中止当前未发货订单（需平台审核）
  4. 系统记录下架操作日志（审计）
- ⚠️ **待确认**：中止在途订单的补偿流程？用户退款逻辑？
- **实现状态**：⬜ 待实现
