# 帧素材打印与裁切排产

> 确认与实施日期：2026-08-25  
> 当前范围：材料包款的帧素材生产顺序、生产批次候选筛选和顺序快照。真实打印文件、标签和机器裁切参数仍属于后续阶段。

## 一、简单说明

商品款式和帧素材生产方式是两件事。基础款、宝盒款等产品结构可能不同，但只要帧图尺寸和纸张版式相同，就应连续打印和裁切，避免频繁更换模具。

`admin-models.html` 中的款式/SKU排序继续用于商品管理和同一生产规则内的款式先后，不再作为完整打印规则。新的 `admin-print-production.html` 专门管理打印裁切组和适用规格。

打印裁切设置会直接改变整批生产顺序，首版只允许负责人维护。生产人员可以在生产批次中查看已经冻结的执行顺序，但不能修改全局规则。

## 二、已确认排序规则

系统按以下顺序冻结每个新生产批次的帧素材队列：

1. 打印裁切组顺序；
2. 同组内的成品帧数规则顺序；
3. 同一规则内按款式集中；
4. 同一款式内按支付成功时间；
5. 最后使用生产件编号稳定排序。

已确认示例：

```text
1. 12帧 5×5cm 基础款
2. 12帧 5×5cm 宝盒款
3. 24帧 5×5cm 基础款
4. 16帧 5×5cm 基础款
5. 12帧 8×8cm 基础款
```

24帧排在16帧之前，是因为12帧和24帧共用“每页12帧”的版式和裁切模具；24帧每件打印两页。16帧使用另一版式，需在共用版式完成后再切换。

## 三、打印裁切设置

### 打印裁切组 `PrintCutGroup`

表示一套可以连续生产的纸张与裁切方式，记录：组名、尺寸、纸张、每页帧数、裁切模具、模板标识、生产顺序和启停状态。

尺寸从现有 SKU 规格中选择，避免 `5×5cm`、`5*5cm` 等手工写法不一致。修改每页帧数后，组内规则的每件页数自动重新计算。

### 适用规则 `PrintCutRule`

使用“尺寸 + 成品帧数”匹配打印裁切组，不按款式、材质或颜色重复配置。例如：

- `5×5cm + 12帧` -> 每页12帧组，共1页；
- `5×5cm + 24帧` -> 每页12帧组，共2页；
- `5×5cm + 16帧` -> 每页16帧组，共1页。

现有启用 SKU 如果没有适用规则，其订单会明确显示“尚未设置打印与裁切方式”，不能进入新生产批次。

## 四、创建生产批次

候选订单可按以下条件筛选：

- 支付成功开始/结束日期；
- 用户总订单号；
- 订单来源；
- 款式、SKU、尺寸、帧数；
- 打印裁切组；
- 只看资料完整；
- 只看材料包充足。

员工筛选后手动勾选订单，也可以全选当前结果。页面同时汇总已选总订单数、生产件数和预计打印页数。

筛选只用于寻找订单，不改变“一张总订单整体生产和一起发货”的规则。如果 SKU 筛选只命中总订单中的一件，页面会说明还包含多少件其他商品；创建批次时仍将整张 `SO` 及其全部 `PU` 一起加入。

## 五、批次快照

创建 `PB` 时，每个 `ProductionBatchUnit` 保存打印裁切组、适用规则、预计页数和连续生产序号；批次主表同时保存完整打印计划快照。

以后调整组顺序、帧数顺序、款式顺序或版式参数，只影响之后创建的批次。已经创建的批次继续使用原快照，防止生产中途顺序变化。

批次详情目前可查看冻结后的帧素材打印顺序。材料领取仍按 SKU 汇总，是另一条并行队列，不强行与打印队列使用同一顺序。
