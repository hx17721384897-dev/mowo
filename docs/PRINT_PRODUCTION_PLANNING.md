# 帧素材打印与裁切排产

> 首次实施：2026-08-25
> 逐 SKU 修订：2026-08-25
> 当前范围：材料包款的帧素材顺序、生产批次候选筛选和顺序快照。真实打印文件、标签和机器裁切参数仍属于后续阶段。

## 一、简单说明

商品 SKU 在 `admin-models.html` 建立。打印设置不重新创建 SKU，只把已有真实 SKU 分配给一种打印裁切方式。

打印设置采用两级结构：

1. 一级 `PrintCutGroup`：一套纸张、尺寸、单页数量、裁切模具和排版模板，例如“A4纸 · 5×5cm · 单页12帧”。
2. 二级 `PrintCutRule`：一个来自款式管理的真实 SKU。每条记录保存 SKU 所属打印组、组内顺序和预计页数。

没有额外的“尺寸组”或“版式子组”。一个 SKU 同一时间只能属于一个打印裁切组。

## 二、为什么逐 SKU 配置

旧实现按“尺寸 + 帧数”汇总。同一个 `5×5cm 12帧` 下的基础款、宝盒款、不同材质和颜色会被视为一项，新建 SKU 也会被自动覆盖，管理员无法确认真实范围。

当前实现逐个显示和保存 SKU：

- SKU 图片；没有 SKU 图片时使用款式图片；
- SKU 编码和数据库 ID；
- 所属款式、尺寸、帧数、材质、颜色和上下架状态；
- 所属打印组、组内顺序和预计页数。

新建 SKU 会自动进入“尚未配置的 SKU”，必须由管理员明确分配，不会被旧汇总规则静默覆盖。设置页同时显示上架和下架 SKU 并标明状态，方便核查历史配置；停用 SKU 仍不能进入生产。迁移时旧汇总规则保留为停用历史，并为当时匹配的 SKU 生成独立配置，不删除历史数据。

## 三、打印裁切组

`PrintCutGroup` 记录：组名和自动编码、纸张、帧图尺寸、单页容纳帧数、裁切模具、排版模板、组顺序和启停状态。

一个组可以放不同成品帧数的 SKU。例如“A4纸5×5cm单页12帧”可以同时包含12帧和24帧 SKU：12帧预计1页，24帧预计2页。系统使用 `向上取整(成品帧数 / 单页帧数)` 计算页数。

添加 SKU 时只推荐与打印组尺寸完全相同、且尚未分配的现有 SKU。弹窗支持按款式或编码搜索，并按帧数、材质和颜色筛选及批量添加。

## 四、拖拽与排序

后台支持：

- 拖动一级打印组调整整批大顺序；
- 拖动组内 SKU 调整二级顺序；
- 把尚未配置 SKU 拖入尺寸相同的打印组快速添加；
- 把已配置 SKU 拖到另一个同尺寸打印组进行移动；
- 把已配置 SKU 拖回“尚未配置”区域进行移出。

新生产批次按以下顺序冻结队列：

1. 打印裁切组顺序；
2. 组内具体 SKU 顺序；
3. 同一 SKU 按支付成功时间；
4. 最后按生产件编号稳定排序。

```text
1. A4纸5×5cm单页12帧
   1. 基础款 / 12帧 / 椴木 / 原色
   2. 宝盒款 / 12帧 / 椴木 / 原色
   3. 基础款 / 24帧 / 椴木 / 原色
2. A4纸5×5cm单页16帧
   1. 基础款 / 16帧 / 椴木 / 原色
3. A4纸8×8cm单页12帧
   1. 基础款 / 12帧 / 椴木 / 原色
```

## 五、尚未配置 SKU 的生产预警

未配置 SKU 不再静默进入正常打印队列，也不作为不可绕过的硬阻断。

创建批次时系统必须：

1. 在候选订单中逐项显示“SKU 尚未确认打印与裁切组”；
2. 显示已确认的预计页数和待确认生产件数量；
3. 第一次提交返回风险清单，不创建批次；
4. 管理员明确确认后才允许继续；
5. 把未配置生产件排在打印队列末尾；
6. 页数保留为空，并在批次快照标记“未配置 SKU，待现场确认”；
7. 在批次详情持续展示提醒，不只弹出一次。

这样既能处理紧急生产，也不会假装系统已经知道正确版式。正式打印前仍建议先完成配置。

## 六、创建生产批次

候选订单可按支付成功日期、总订单号、来源、款式、SKU、尺寸、帧数、打印组、资料完整和材料充足筛选。

筛选只用于寻找订单，不改变“一张总订单整体生产和一起发货”。若 SKU 筛选只命中订单中的一件，系统提示额外商品数量，创建时仍加入完整 `SO` 和全部 `PU`。

创建 `PB` 时，每个 `ProductionBatchUnit` 保存打印组、SKU规则、预计页数和生产序号；主批次保存完整打印计划快照。以后修改组或 SKU 顺序只影响新批次，旧批次继续使用创建时的快照。

## 七、权限和审计

打印排序会影响整批生产，首版只有负责人拥有 `PRODUCTION_CONFIG` 权限。普通生产人员可查看冻结后的执行顺序，不能修改全局规则。新增、移动、排序和移出操作进入后台操作日志。

专项命令：`npm run check:print-production`。

自动验证包括：逐 SKU 添加和资料展示、图片展示、同尺寸推荐、页数重算、拖拽快速加入、两级顺序、支付日期筛选、混合订单整单提示、未配置预警和确认、未配置项末尾快照、旧批次顺序稳定及批次详情展示。
