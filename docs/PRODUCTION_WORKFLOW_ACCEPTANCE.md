# 生产履约流程验收清单

> 建立日期：2026-08-26；最后更新：2026-08-29
> 范围：材料包款正常生产主流程，以及打印/裁切损坏的指定页返工。

## 已自动确认

- 数据库将付款事实与生产履约阶段分开记录。
- 正式批次按完整 `SO` 建立，一个订单的全部 `PU` 一起进入同一个 `PB`。
- 创建批次后进入待处理，并自动尝试生成冻结 Word。
- 地址按总订单一行导出；旧地址接口不能覆盖正式批次。
- 面单绑定到 `SO`，并同步锁定该订单全部 `PU`。
- 缺少 Word 的产品会阻止生产资料导出，并明确列出 `PU`、规格和真实失败原因；模板缺失、动画版本缺失和文件生成错误不会再显示成同一种提示。
- 商品总帧数不必被模板单页容量整除；例如 8×8cm、16 帧使用每页 6 帧模板时生成三页，最后一页只放 4 帧。
- 批次创建后才补上传的模板，会在再次导出生产资料时自动为旧批次补生成 Word。
- 首次生产资料导出建立唯一 `FP`；重复下载不重复建码、不重复扣库存。
- 生产资料包含 Word、帧包标签 CSV 和材料需求 CSV。
- 帧包完成、材料领用、单件配对和装箱发货使用四个独立岗位页面与四条独立状态，任一操作都不会顺带完成其他环节。
- 材料领用按 `PB + KB/BX + 数量` 预留库存；未配对数量可以带原因退回，领用动作不提前扣减实物库存。
- `FP + KB/BX` 配对会校验 SKU、帧包完成状态、当前生产件领料状态和本批次领料记录，并在成功时条件扣减一套材料。
- 同一箱码含多个 `KB` 批次时，只能消耗当前 `PB` 已领且尚有余额的批次，不能误取箱内其他库存。
- 装箱扫码保存在数据库，刷新页面后不会丢失。
- 错订单、未配对产品和作废帧包不能加入当前面单。
- 未齐订单保留在待齐套区；全部 `PU` 齐全后才进入待发货。
- 发货时再次检查配对、装箱和异常状态，并同步更新总订单、生产件、帧包、配对和批次。
- 订单环节页只读取正式 `SalesOrder` 和生产批次数据，不再使用旧单件定制订单状态推进生产。
- 批次页只做创建、总览、文件与进度查询，不再重复提供地址、面单和生产资料操作。
- 未配对帧包支持选择指定页重印；生成新 `FP` 尝试，旧码作废并保存原因、页码、操作人和时间。
- 重印 Word 只包含指定页，例如 24 帧两页仅第 2 页损坏时，文件只生成第 2 页，但身份仍由 `FP-01` 更新为 `FP-02`。
- 已经配对的帧包会阻止直接重印，避免材料库存与单件绑定被绕过。
- `npm run check`、`check:production-batches`、`check:production-artifacts`、`check:inventory-traceability` 和 `check:production-workflow` 已通过核心检查。
- `npm run check:production-scan-ui` 已用临时生产员工真实打开五个页面，验证三级菜单、无需聚焦输入框的扫码捕获和手机宽度布局，测试账号已自动清理。
- 五个扫码页面会使用带版本号的菜单脚本，避免浏览器继续显示旧“扫码生产”；当前岗位会自动展开并高亮，帧包、领料、配对、装箱分别使用蓝、橙、青、绿标识。
- 扫码分类同时兼容正式 `KB-...` 和本地历史库存 `LEGACY-KIT-...`；历史批次仍必须通过后端库存、SKU 和当前生产批次领用校验。
- 已使用一笔包含两个 `PU` 的本地测试订单实际跑通：两次 `FP + KB` 配对、两件装箱、整单发货；测试后订单、批次和库存已恢复，未残留测试帧包或材料批次。
- 已实际调用指定页返工接口：24 帧两页只重印第 2 页，下载 Word 只有一页 12 个帧位；`FP-01` 作废、`FP-02` 生效，返工记录完整，测试数据清理后为 0。

## 需要负责人手动确认的界面

1. “订单生产”下的已付款、待处理、处理中、待生产、生产中、待发货和已发货页面是否符合员工实际操作顺序。
2. 面单批量填写采用“总订单号, 快递单号, 快递公司”逐行录入是否方便；后续是否需要直接上传快递平台文件。
3. 帧包标签 CSV 的字段是否足够，实际标签尺寸、二维码/条形码样式和一式两张排版仍需拿真实标签纸确认。
4. 材料需求 CSV 是否方便打印给配料人员；若不方便，再生成专用打印页或 PDF。
5. 在“帧包完成”页直接扫 `FP`，确认单件只推进帧图状态。
6. 在“材料领用”页选择 `PB` 后扫 `KB/BX`、填写数量，确认只产生预留；测试部分退回后数量是否正确。
7. 在“单件配对”页先扫一次当前材料来源，再连续扫多个 `FP`，确认系统自动消耗本批次已领数量且不会串用其他箱内批次。
8. 在“装箱发货”页先扫快递面单，再逐件扫 `FP`，确认多件订单未齐时留在等待区、齐套后才允许发货。
9. 使用真实扫码枪测试快速连续扫码、扫码失败提示音和更换岗位页面后的识别是否符合现场习惯。
