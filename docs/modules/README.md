# modules - 代码模块调查索引

本目录记录“代码现在实际做什么”，不替代产品规划文档。每个模块文档统一包含：职责、技术实现、入口与前缀、文件依赖、数据表、接口、前端消费者、关键流程、文档差异、风险、待确认项和调查覆盖率。

当前首发开放、关闭和延后讨论的范围先读 `../RELEASE_SCOPE.md`；模块文档中的“代码存在”不等于首发启用或已经达到上线质量。
各产品阶段的上线门槛、工程就绪等级和跨模块责任域见 `../LAUNCH_READINESS.md`。
实际代码整改的功能区顺序和完成标准见 `../REMEDIATION_ROADMAP.md`。
联名商品、私人定制、混合购物车、小程序交接、支付和生产之间的统一端到端关系见 `../WEB_COMMERCE_END_TO_END.md`。

## 阅读提醒

- “文件存在”不等于“页面可用”；必须继续核对页面入口、API、数据库和异常路径。
- “有权限中间件”不等于“所有路由已使用”；权限结论要落到每个接口。
- “Schema 有表”不等于“迁移或生产库已有表”；数据库最终状态需要三方核对。
- 旧路由和新路由同时存在时，两条路径都要记录，不能只写推荐路径。
- 每份模块文档的有效性和下一次复核动作见 `../DOCUMENTATION_STATUS.md`。
