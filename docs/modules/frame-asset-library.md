# 后台帧图资产总库

> 首版实施日期：2026-08-26；2026-09-04 增加已编辑序列帧的文件夹批量导入。本文件记录当前已经实现的后台总库、制作草稿、批量导入、生产文件、权限、来源与授权边界。用户侧动画资产和 V1/V2 规则见 `animation-assets.md`，打印细节见 `../PRINT_PRODUCTION_PLANNING.md`。

## 简单说明

帧图资产总库是哞屋内部统一资料库，收纳网站定制、线下定制、创作者联名投稿以及公司内部设计或测试动画。进入总库只代表“资料被登记和受控保存”，绝不代表哞屋取得销售、公开展示或给其他客户复用的权利。

每套动画使用一个 `ANM-YYYYMMDD-XXXXXX` 编号。`ANM` 代表“这套动画是什么”，不是订单号、定制申请号或生产任务号。一套动画可以有 V1、V2 等不可覆盖版本；旧订单继续引用成交时的旧版本。

## 来源与用途必须分开

`sourceChannel` 只回答“从哪里来”：

| 值 | 含义 |
|---|---|
| `WEB_CUSTOM` | 用户走网站定制流程形成 |
| `OFFLINE_CUSTOM` | 工作人员为线下客户登记 |
| `CREATOR_SUBMISSION` | 创作者提交或工作人员代录 |
| `INTERNAL_CREATED` | 哞屋内部制作或测试 |

`usageType` 回答“当前允许怎么用”：

| 值 | 含义 |
|---|---|
| `PRIVATE_CUSTOM` | 只用于对应客户的私人订单 |
| `COLLAB_SALE` | 已进入联名销售用途 |
| `COMPANY_PRODUCT` | 公司自有并可作为商品使用 |
| `INTERNAL_TEST` | 仅内部测试 |
| `UNDECIDED` | 用途尚未确认 |

来源不能自动推导用途。尤其是线下定制，即使帧图已经进入总库，只要 `authorizationStatus` 不是 `AUTHORIZED`，后端就拒绝把它改成联名销售或公司商品。

## 线下客户与账号后绑定

1. 客户没有网站账号时，负责人填写客户/权利人名称和联系方式，以“线下客户 + 私人定制 + 仅限私人使用”登记。
2. 此时 `ownerUserId` 可以为空，动画仍有独立 `ANM` 和 V1，不依赖临时姓名充当数据库主键。
3. 客户以后注册网站账号后，负责人编辑资料并填写该账号手机号即可绑定；系统同时更新该动画已登记帧图的文件归属。
4. 绑定账号只改变“这个网站账号可以被识别为所有人”，不会改变用途和授权状态。
5. 未经客户明确授权，素材只能用于该客户自己的订单，不能公开销售、转给其他客户或进入可复用公共素材池。

## 页面能力

- 按私人定制、联名销售、公司自营、内部测试、资料不完整、用户已删除和已归档分类查看。
- 支持按 `ANM`、标题、权利人、账号、`DZ`、`SO` 和标签搜索。
- 卡片只加载当前版本首帧；点击详情后才取得短期预览地址并加载完整帧序列，避免一次返回整个总库原图。
- 详情展示当前用途、权利主体、授权状态、绑定账号、标签、全部版本，以及定制、联名和订单关联。
- 卡片和详情直接列出按尺寸、目标帧数、纸张容量和文件版本命名的 Word 生产文件；没有文件时显示“生产文件：尚未生成”。点击文件名使用短期签名地址下载。
- 详情中的每个生产文件提供“查看加工帧”，弹窗按 `frame-001.png`、`frame-002.png` 顺序显示所复用的加工 PNG、像素尺寸和角标状态。查看行为写入审计日志。
- 负责人可以删除尚未绑定生产批次的错误 Word 版本；删除会移除数据库记录和对应 Word 物理文件，但不删除动画原帧和可被其他文件复用的加工 PNG。已入批文件必须通过后续生产异常流程处理，不能从资产详情直接删除。
- 负责人和生产人员可以在详情点击“新增文件版本”，选择动画 Vn、目标商品帧数和兼容模板。核心帧只拼接一轮，目标帧通过循环插入；相同动画版本和尺寸复用无损拼接 PNG。
- 负责人可以人工导入 1 至 50 张帧图，按文件名自然顺序生成 ANM 和 V1，也可以编辑资料、归档、恢复和在极严格条件下永久删除。

## 后台帧图制作流程

“帧图制作”是后台内部工作台，不建立 `DZ`、购物车、`SO` 或生产任务。任务列表、导入入口、状态管理及完整帧编辑均由 Vue `/app/admin/frame-making` 和 `/app/admin/frame-making/:id` 承载，并复用 Vue 编辑器核心能力；旧 `admin-frame-making.html` 及旧共享编辑器的 `frameDraftId` 分支已物理删除，因此不会形成第二套制作实现，也不会进入选款式或购买流程。

1. 负责人或生产人员导入一个视频、一个 GIF，或最多 50 张图片；合计不超过 200MB。
2. 上传完成后生成独立 `FD` 制作草稿。原素材使用 `LIBRARY_SOURCE` 私有用途并绑定该草稿，不会被当成正式帧图。
3. 完整编辑器直接复用用户侧已验证功能：视频片段时间轴、范围拖动与选段播放、30fps 候选帧提取、感知去重、快速抽帧、逐帧预览、播放速度、克隆、删除、排序和 30 步撤销；GIF 和图片组沿用同一编辑能力。
4. 筛选结果每 15 秒自动保存到 `FrameAssetDraft.editorData`；点击顶部或底部“保存并返回”也会先保存。重新进入同一 `FD` 时恢复已选帧和播放速度。旧版试制页面保存的 `selectedIds` 仍可兼容恢复，但新流程统一写 `selectedIndexes`。
5. 草稿使用 `revision` 防止两名员工同时保存时静默覆盖；发生冲突时要求刷新后继续。
6. 生产人员完成后点击“提交负责人确认”，状态由 `DRAFT` 变成 `READY_FOR_REVIEW`，此后生产人员不能继续修改；负责人从“待负责人确认”列表进入同一完整编辑器复核。
7. 负责人点击“填写入库资料”，确认素材来源、用途、权利主体、授权状态、绑定账号、标签和内部备注后，才能生成正式 `ANM + V1`。负责人也可以直接完成自己建立的草稿并入库。
8. 正式帧图使用 `LIBRARY_FRAME` 私有用途；最终动画限制为 1 至 50 帧。重复确认同一草稿不会生成第二套动画。
9. 发布后的 `FD` 仍保留，并关联生成的 `ANM`，因此以后可以追查原素材、编辑记录和正式版本之间的关系。
10. 草稿建立者或负责人可以放弃未完成草稿。放弃是工作状态，不等于立即永久删除原素材；公司的内部原素材按当前决策长期保留，未来统一纳入留存策略。

`FD` 只代表一次后台制作工作，`ANM` 才代表一套可被版本、订单和生产引用的动画资产，两者不能合并为一个编号。

## 已编辑序列帧批量导入

“批量导入”面向已经完成编辑的 PNG/JPG 序列帧，不进入视频筛选器，也不建立 `FD` 草稿。负责人在浏览器选择一个总文件夹；总文件夹下第一层的每个子文件夹代表一套动画，子文件夹内只允许数字命名的 PNG/JPG。系统按数字自然顺序排列，允许 2、4、12、16 等不同帧数。

浏览器文件夹入口不读取 Word 文档。若总文件夹内直接放置 `.docx`，即使文档中嵌有图片，也不会被识别为动画；应先把每套动画导出为独立子文件夹，并以 `1.png`、`2.png`（或 JPG）等数字文件名存放。2026-09-28 人工复核已确认符合该目录协议的素材可以成功读取。

1. 一次导入建立一个 `FI-YYYYMMDD-XXXXXXXX` 批次；`FI` 只追踪上传和入库工作，不替代每套动画自己的 `ANM`。
2. 当前上限是每批 100 套、2000 张、500MB；每套 2 至 50 张，单张不超过 20MB。浏览器同时上传 4 张，避免瞬时占满连接和本地服务；瞬时网络或服务器错误会自动再尝试一次。
3. 公司批次默认“内部制作 + 内部测试 + 公司权利主体 + 仅限内部使用”；客户批次默认“线下客户 + 私人定制 + 客户权利主体 + 仅限私人使用”。客户批次必须填写客户或权利人名称；公司商品用途必须明确标记已授权。
4. 共同资料可以一次应用到全部；勾选任意项目后可以批量添加标签、移除标签或修改用途；名称、标签、用途和权利人仍可逐套修改。标签的批量添加是合并，不覆盖已有标签。
5. 上传完成后服务器重新检查真实文件状态、MIME、图片尺寸、数字序号和资料规则，并用按帧顺序排列的文件 SHA-256 建立内容指纹。同组尺寸不同或序号不连续属于提醒；上传缺失、图片损坏或权利资料不合法会阻止该套入库。管理员修正被拦资料后点击“重新检查”，不必重新上传整批文件。
6. 内容和顺序与已有批量资产完全相同时默认跳过；负责人可以在明确确认后勾选“仍然导入”。名称相同但图片不同不会被当作内容重复。
7. 正式入库逐套使用独立数据库事务：成功的一套生成自己的 `ANM + V1` 并绑定私有帧图；失败的一套保留原因，可单独重试，不回滚同批其他成功动画，也不会留下半套资产。
8. 批次记录保留原文件夹名称、逐套状态、生成的 ANM、操作人、数量和时间。中断后未绑定资产的私有上传文件沿用 24 小时自动清理规则；过期后需要重新建立导入批次。
9. 当前首版使用浏览器文件夹选择，不接受 ZIP，也尚未提供 Excel 导入资料；大量共同字段通过页面统一应用和勾选批量操作完成。

## 权限与文件安全

| 岗位 | 总库权限 |
|---|---|
| `OWNER` 负责人 | 查看、建立、编辑、绑定账号、归档、恢复和受限永久删除 |
| `PRODUCTION` 生产人员 | 查看正式总库、生成生产文件；可以建立、筛选和编辑制作草稿，但不能正式发布或更换全局 Word 模板 |
| `COLLAB_OPS` 联名运营 | 只读查看帧图与关联信息 |
| `CUSTOMER_SERVICE` 客服 | 不能浏览总库；只能按具体客服/售后业务查看其已有权限的附件 |
| 普通用户 | 不能进入后台总库，只能通过用户侧接口访问自己的可见动画 |

帧图保存在私有存储，浏览器得到的是短期签名地址，不返回内部 object key。查看具体版本或生产加工帧会写入 `AuditLog`。列表采用分页和延迟加载，避免大量访问时一次读取全部记录和全部帧图。

## 联名资料关联

- 新提交的 `CollabWork` 必须关联一个动画资产和具体版本。
- 如果创作者从自己已有动画发起联名，联名记录复用该 `ANM + Vn`，不复制成另一套动画。
- 如果是旧联名入口直接提交帧图，系统补建 `CREATOR_SUBMISSION` 来源的 ANM 和 V1。
- 联名审核通过后才把授权状态变成 `AUTHORIZED`；拒绝且没有其他有效联名关系时，创作者投稿资料归档或原私人动画退回非联名状态。
- `npm run assets:backfill-collab` 用于给历史联名记录补齐动画和版本关联；2026-08-25 本地执行结果为关联 9 条、跳过 0 条。

## 归档与永久删除

归档是日常整理动作：资料从正常工作列表移到“已归档”，文件、版本、订单、联名和审计记录都保留，并可由负责人恢复。

永久删除只允许负责人操作，并且当前实现同时要求：

1. 来源必须是 `INTERNAL_CREATED`；
2. 用途必须是 `INTERNAL_TEST`；
3. 只有最初 V1，没有 V2 等历史版本；
4. 没有 `CustomProduct`、定制申请、订单商品、联名作品、已拼接帧或生产文件关联；
5. 通过数据库事务删除记录后再清理物理文件，并写入审计日志。

私人用户素材、线下客户素材和联名素材无论当前是否有订单，都不能从本页面永久删除，只能归档。生产任务通过订单商品锁定动画版本，因此存在订单商品时删除一定会被拦截。

`npm run check:production-artifacts` 不依赖业务数据，验证一页 12 格 Word 模板、24 帧自动扩页、图片关系和核心帧循环插入。数据库接口与真实页面验收需要先应用 `20260826190000_add_print_templates_and_artifacts` 迁移。
