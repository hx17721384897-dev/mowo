## 5. 当前规则

- 小程序未实现的页面要明确显示未开放，不得出现“支付成功”“订单已提交”等虚假完成文案。
- 所有 API 数据结构以服务端响应为准；小程序类型必须是适配层或共享契约生成物，不能继续手工猜测 Prisma 字段。
- Token、用户 ID、领取凭证都不得通过 URL 传递。微信小程序会话不能依赖浏览器 Cookie 续期。
- 每次小程序源代码改动必须独立提交；构建产物、`node_modules`、AppID、密钥和真机配置不提交。
